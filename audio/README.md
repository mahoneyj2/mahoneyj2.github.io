# Terminal sound effects

Five unmodified samples from **Interface Sounds (1.0)** by Kenney (2020),
released under **Creative Commons Zero (CC0 1.0 Universal)**.

- Original pack: https://kenney.nl/assets/interface-sounds
- WAV distribution: https://github.com/Calinou/kenney-interface-sounds
- Licence: [LICENSE.txt](LICENSE.txt)

| File | Use |
| --- | --- |
| `open_001.wav` | Power on |
| `close_001.wav` | Power off |
| `select_001.wav` | Section selection and enabling sound |
| `click_001.wav` | BIOS checks |
| `confirmation_001.wav` | Terminal ready |

Playback volume is reduced in `sound.js`. These are original Kenney assets,
not recordings extracted from Fallout.
